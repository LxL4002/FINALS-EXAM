# Activity 4: Google Sheets Presentation

## Activity Description

This activity focused on introducing and presenting Google Sheets to the class. We discussed what Google Sheets is, its different features and functions, and how it can be used to organize, manage, and analyze data. We also demonstrated how to use the application, allowing our classmates to understand its basic tools and practical applications.

## What Have I Learned?

Through this activity, I learned how to use Google Sheets and became more familiar with its features, tools, and functions. I gained a better understanding of how to create and organize spreadsheets, input and format data, and use formulas to perform basic calculations. One challenge I encountered was explaining and demonstrating the different features clearly, but I addressed this by familiarizing myself with the application and practicing the steps before presenting. This activity also helped improve my confidence and communication skills when discussing technological concepts in front of others. In the future, I can apply what I learned to organize academic information, manage research data, and perform calculations more efficiently. I also hope to explore more advanced functions to further improve my skills in using Google Sheets.
